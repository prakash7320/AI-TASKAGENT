# 🚀 AI Task Agent

> A full-stack AI assistant that combines intelligent chat, voice interaction, real-time weather, Google Calendar automation, Firebase authentication, cloud chat history, and file attachments in one responsive productivity workspace.

## 🌐 Live Demo

🚀 **[Open AI Task Agent](https://ai-taskagent.vercel.app/login)**

## ✨ Features

* 💬 **Smart AI Chat** — Interactive conversations powered by Gemini AI.
* 🎤 **Voice Input & Output** — Speak to the AI and listen to responses with built-in TTS and mute controls.
* 📱 **Mobile-First Design** — Responsive interface with mobile slide-in navigation and widget handling.
* ⛅ **Real-Time Weather** — Fetch weather information and display useful metrics in the dashboard.
* 📅 **Google Calendar Integration** — Create and manage meeting schedules through natural-language requests.
* 🔐 **Firebase Authentication** — Secure user login and session management.
* 💾 **Firebase Firestore** — Persist chat history in the cloud.
* 📎 **File Attachments** — Upload images and PDFs directly into conversations.
* 📊 **Task Orchestration Dashboard** — Visualize AI status, tool execution, weather, and upcoming meetings.

## 🔐 Authentication & Data

Firebase Authentication handles user login and session management. Firebase Firestore is used to persist conversation history in the cloud.

## 📸 Dashboard

The dashboard brings the main AI workspace into one interface:

* AI conversations
* Task orchestration
* AI execution status
* Live weather and metrics
* Upcoming meetings
* Chat history
* File attachments
* Voice controls
